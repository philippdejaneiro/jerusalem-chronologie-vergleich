# Vergleich: Datierung der Zerstörung Jerusalems

Dieses Repository sammelt und vergleicht strukturierte Daten, historische Belege und theologische Argumente zur Datierung der Zerstörung Jerusalems durch Nebukadnezar II.

## Untersuchte Positionen
1. **Chronologie von Jehovas Zeugen (jw.org):** Datierung auf **607 v. u. Z.** (basierend auf der biblischen Berechnung der 70 Jahre Exil).
2. **Akademische Geschichtswissenschaft & Archäologie:** Datierung auf **587/586 v. u. Z.** (basierend auf babylonischen Chroniken, astronomischen Keilschrifttexten wie VAT 4956 und Regierungslisten).

## Aufbau des Repositories
- `/data`: Strukturierte JSON- und CSV-Dateien für Auswertungen.
- `/analysen`: Detaillierte Themen-Dossiers im Markdown-Format.
